# PSI West widget

Android home-screen widget showing Singapore's West region air quality from NEA (via data.gov.sg):

- 1-hr PM2.5, colour-coded by NEA band (I Normal, II Elevated, III High, IV Very high)
- 24-hr PSI with its descriptor
- Refreshes hourly; tap the widget to refresh now

## Install

On your phone, open https://github.com/geraldinelek/PSI-Widget-/releases/latest/download/PSI-West-Widget.apk, download, and open the file. Allow installs from your browser if Android asks.

Then long-press the home screen, tap Widgets, and drag PSI West onto the screen.

## Build

Every push to `main` builds a new APK with GitHub Actions and publishes it as a release.
